# Pergamenum

A native, fully offline macOS app that merges a local markdown vault, an infinite
spatial Workspace canvas, and an integrated task and calendar system into one tool.

Full specification in `docs/20260811_Pergamenum_SpecApp.md`, condensed context in
`PROJECT_BRIEF.md`.

## Status

Bootstrap - under active development. The repository currently contains the Tuist
scaffolding, a minimal SwiftUI app shell, and one passing test. Feature work starts
at milestone M0 (design system).

## Requirements

- macOS 26 Tahoe or later, Apple Silicon
- Xcode 26 with Swift 6
- [Tuist](https://tuist.dev) 4.x (`brew install tuist`)

## Getting started

```bash
tuist generate --no-open
xcodebuild -workspace Pergamenum.xcworkspace -scheme Pergamenum -destination 'platform=macOS' build
xcodebuild -workspace Pergamenum.xcworkspace -scheme Pergamenum -destination 'platform=macOS' test
```

The `.xcodeproj` and `.xcworkspace` are build artifacts generated by Tuist and are
not tracked in git. Change `Project.swift` and regenerate instead of editing them.
